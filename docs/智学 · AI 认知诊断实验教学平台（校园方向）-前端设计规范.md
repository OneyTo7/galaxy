# 智学·AI 认知诊断实验教学平台 - 前端设计规范

> 版本：1.0 | 最后更新：2026-10-03

---

## 一、设计概念

**"轻松专业的教育仪表盘"**：浅色明亮底色（冷白 `#F7F9FF`），主色蓝 `#4F7CFF` 贯穿按钮/链接/数据高亮/图表，微动效（200ms ease-out）增强反馈但不喧宾夺主。禁止网格/光晕/粒子/霓虹，靠留白、色板层次、圆角和柔和阴影撑起专业感。

## 五、动效规则

全部 200-300ms ease-out，禁止闪烁/持续循环/大动画。

| 场景 | 效果 |
| --- | --- |
| 按钮点击 | scale(0.96) 回弹 |
| 卡片 hover | translateY(-2px) + 阴影加深 |
| 页面/抽屉切换 | 淡入 + 轻微位移 |
| 进度条/得分 | 数值渐进增长 |
| 提交成功 | 成功图标轻微弹跳 |

**禁止**：网格/噪点/发光光晕/霓虹渐变/扫描线/粒子/持续漂浮大动画。

## 九、硬性禁止项

1. 禁止自定义颜色（只用色板内色值）
2. 禁止复杂背景纹理（网格/噪点/光晕/粒子/霓虹）
3. 禁止超大圆形装饰元素
4. 禁止信息拥挤（保证充足留白）
5. 禁止持续循环大动画
6. 禁止单独写 scoped 样式（全站复用全局组件类）
